Reviewed 2026-11-19; every exception expires 2026-12-19. These findings are **not fixed**.
The exact package/version/advisory/scanner entries are in `config/security-exceptions.json`.
Unknown or expired exceptions fail CI. Trivy HIGH/CRITICAL and all pip-audit advisories
remain blocking unless listed. Lower Trivy severities are reported below, not hidden
or exempted: the requested image threshold is HIGH. UNKNOWN is not a low-risk claim.

Evidence: final local API image Trivy scan and isolated runtime-plus-development
pip-audit. Package/advisory rows deduplicate aliases; raw scanner counts can include
duplicates. CPU torch builds are skipped by pip-audit when absent from PyPI;
Trivy scans the image dependency metadata too. Neither scanner proves absence of flaws.
The final frontend image scan reported zero findings; npm audit reported zero.

Reachability review searched backend for FileResponse, StaticFiles, UploadFile,
request.form, HTTPEndpoint, request.url, from_pretrained, save_pretrained, pyarrow,
SentenceTransformer and CrossEncoder. Absence of a direct call is not proof that
transitive code is unreachable. Model-artifact loading is active and remains risky.
OS advisories without a fixed version are temporary accepted risks, not false positives.
No framework or ML migration was performed. Follow-ups are `chore/upgrade-web-stack`
and `chore/upgrade-ml-stack`; the latter requires before/after retrieval evaluation.
